# SpiroLab 5.1

برنامهٔ سادهٔ Windows Forms x86 برای تست زندهٔ MIRUSB و خروجی محلی JPG + JSON. مسیر اجرای آن به MIR Spiro، WinspiroPRO یا mirwsp.dll وابسته نیست. بستهٔ خصوصی درایورِ صادرشده از همین ویندوز جدا تحویل می‌شود؛ نصب و تست آن روی رایانهٔ دوم هنوز انجام نشده است.

## اجرا

`run.bat` یا `app\release\SpiroLab.exe` را باز کنید. در بستهٔ قابل‌حمل Launch.cmd و EXE آماده‌اند؛ کامپایلر یا سورس لازم نیست. .NET Framework 4.x ویندوز لازم است.

در «تنظیمات»، نام مرکز و کارشناس پیش‌فرض را ذخیره کنید. نام مرکز پیش‌فرض «شرکت سنگ آهن مرکزی ایران - بافق» و کارشناس خالی است. «مراجع جدید» این پیش‌فرض‌ها و تاریخ محلی امروز ویندوز را کپی می‌کند. مشخصات، تاریخ معاینه و کارشناس قابل ویرایش‌اند. تاریخ شمسی یا میلادی با قالب سال/ماه/روز پذیرفته و درون برنامه میلادی ذخیره می‌شود.

«شروع تست» فقط از USB واقعی استفاده می‌کند. هر تعداد مانور لازم است انجام دهید؛ سه مانور اجباری نیست (سقف محافظتی پرونده ۱۰۰ مانور). سپس «پایان و گزارش» را بزنید. این کار پرونده را نهایی و اطلاعات و اعدادش را ثابت می‌کند. برای تست تازه «مراجع جدید» را انتخاب کنید. تفسیر دستی اختیاری است. VEXT خودکار هنوز تأیید نشده؛ ورود دستی اختیاری فقط با نام کارشناس، منبع و تأیید بازبینی پذیرفته می‌شود.

«ذخیره JPG + JSON» دقیقاً دو فایل Spirometry-Report.jpg و Spirometry-Data.json را در پوشهٔ یکتای Examination-<snapshot id> می‌سازد. JPG واقعی ۲۴۰۰×۳۳۹۴، ۳۰۰ DPI، کیفیت پیش‌فرض ۹۷ است. JSON نسخهٔ ۲ دقت کامل، تاریخ انتخاب‌شده و زمان واقعی دریافت را جدا نگه می‌دارد. تنظیمات در `%APPDATA%\SpiroLab\settings.xml` و پرونده‌ها در `%APPDATA%\SpiroLab\exams` ذخیره می‌شوند. تغییر تنظیمات پیش‌فرض، پروندهٔ قبلی را عوض نمی‌کند.

## بررسی

- app\build.bat: ساخت Release با کامپایلر ویندوز توسعه.
- app\test.bat: ۷۵ بررسی قبلی + ۶۳ بررسی مستقل قبلی + ۶۶ بررسی اصلاحات = ۲۰۴ بررسی نرم‌افزاری.
- app\Tests\DriverPackageTests.ps1 -PackageDirectory <backup>: شش بررسی بستهٔ خصوصی درایور؛ نصب نمی‌کند.
- tools\package-release.ps1: بستهٔ Portable، نمونهٔ مصنوعی و SHA256.
- SpiroLab.exe --self-test <folder>: ذخیره، بازخوانی و گزارش مصنوعی روی همان میزبان.
- SpiroLab.exe --diagnostics <file.txt>: خروجی وضعیت ویندوز بدون اطلاعات بیمار یا فرمان USB.

اعداد بازسازی‌شده و تحلیل بالینی هنوز اعتبارسنجی دستگاهی نشده‌اند؛ دادهٔ نمایشی با برچسب NON-CLINICAL TEST DATA مشخص است. آزمون رایانهٔ پاک، USB واقعی، BTPS و برابری کامل با فریم‌ور MIR در انتظار شواهد‌اند. هیچ ارتباط وب‌سایت، ورود، API یا آپلودی اضافه نشده است. تاریخ HLine موضوع این مرحله نیست.

مخزن Git محلی ایجاد شده؛ بکاپ پیش از تغییر در phase-backups/before-5.1.zip محفوظ است. دادهٔ بیمار، ضبط خام، بستهٔ خصوصی درایور، خروجی و فایل‌های ساخت از Git کنار گذاشته شده‌اند. push انجام نشده است.
