# SpiroLab 5 — standalone Windows application phase

## وضعیت تحویل

برنامهٔ مستقل Windows Forms x86، گزارش JPG واقعی و JSON نسخهٔ ۲ آماده شده‌اند. نرم‌افزارهای دسکتاپ MIR Spiro / WinspiroPRO و mirwsp.dll در مسیر اجرای برنامه استفاده نمی‌شوند.

**ارتباط سخت‌افزاری همچنان به MIRUSB نیاز دارد.** درایور مستقل رسمی و مجوز بازتوزیع هنوز تأیید نشده‌اند. آزمون ویندوز پاک و تست زندهٔ معتبر انجام نشده‌اند؛ بنابراین راه‌اندازی مستقل دستگاه روی رایانهٔ جدید را موفق اعلام نمی‌کنیم.

## اجرا

روی `run.bat` یا `app\release\SpiroLab.exe` کلیک کنید. بستهٔ Portable فقط EXE، config، راهنما و نمونهٔ مصنوعی دارد؛ کامپایلر، سورس یا فایل اختصاصی MIR در آن نیست. اطلاعات و پرونده‌های محلی در `%APPDATA%\SpiroLab\exams` می‌مانند.

«وضعیت دستگاه» تشخیص سخت‌افزار ویندوز، درایور، پاسخ کنترل و دریافت دادهٔ تست را جدا نشان می‌دهد و گزارش بدون اطلاعات بیمار صادر می‌کند. «شروع تست» منبع USB واقعی دارد؛ قطع بودن دستگاه باعث شروع خودکار شبیه‌ساز نمی‌شود. «حالت آزمایشی» فقط با انتخاب صریح کاربر فعال است.

مشخصات، مرکز و کارشناس را وارد کنید. یک یا چند مانور انجام دهید؛ حداقل سه مانور اجباری نیست. تفسیر دستی کارشناس بعد از تست قابل ورود است. «پایان و گزارش» نسخهٔ ثابت معاینه را می‌سازد. در گزارش «ذخیره JPG + JSON» را بزنید:

```
Examination-<unique snapshot id>/
    Spirometry-Report.jpg
    Spirometry-Data.json
```

JPEG واقعی، ۲۴۰۰×۳۳۹۴ پیکسل، ۳۰۰ DPI، کیفیت پیش‌فرض ۹۷. فقط در نمایش اعداد گرد می‌شوند؛ JSON دقت را نگه می‌دارد. خروجی توسعه‌ای و همهٔ مقادیر بازسازی‌شده همچنان اعتبارسنجی‌نشده‌اند. VEXT برابر null است؛ BEV تخمینی جدا ثبت می‌شود. تصویر و JSON از یک `ExaminationSnapshot` مشترک ساخته می‌شوند.

## بررسی و ساخت

- `app\build.bat`: ساخت Release روی رایانهٔ توسعه؛ برای رایانهٔ کاربر لازم نیست.
- `app\test.bat`: ۷۵ بررسی رگرسیون و ۶۳ بررسی جدید نرم‌افزاری.
- `tools\package-release.ps1`: بستهٔ قابل‌حمل با فایل‌های مجاز، self-test مستقل و SHA256.
- `SpiroLab.exe --self-test <folder>`: آزمون مصنوعی ذخیره، بازخوانی، تصویر و داده، بدون USB.
- `SpiroLab.exe --diagnostics <file.txt>`: فهرست وضعیت فقط‌خواندنی ویندوز، بدون ارتباط USB.

**این آزمون‌ها روی رایانهٔ توسعه‌اند؛ Clean Windows A = PENDING و Hardware B = HARDWARE VALIDATION PENDING.**
