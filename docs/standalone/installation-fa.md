# نصب و کار با SpiroLab 5.1

۱. بستهٔ Portable را استخراج و Launch.cmd یا SpiroLab.exe را اجرا کنید. فایل config همراه EXE بماند. نصب MIR Spiro، WinspiroPRO، Visual Studio و کامپایلر لازم نیست. .NET Framework 4.x ویندوز لازم است. برنامه x86 است؛ درایور خصوصی فعلی برای Windows x64 صادر شده است.

۲. برای رایانهٔ دوم، بستهٔ خصوصی درایور جداست. [راهنمای دقیق نصب درایور](driver-installation.md) شامل دستور بررسی، نصب Administrator و تأیید binding است. در این مرحله فقط export و بررسی امضا/هش انجام شده؛ هیچ درایوری نصب یا جابه‌جا نشده است. نتیجهٔ رایانهٔ دوم و USB زنده در انتظار آزمایش‌اند.

۳. در «تنظیمات» نام مرکز و کارشناس پیش‌فرض را ذخیره کنید. بازنشانی پیش‌فرض تأیید می‌خواهد. مرکز پیش‌فرض «شرکت سنگ آهن مرکزی ایران - بافق» و کارشناس خالی است. سپس «مراجع جدید» را بزنید تا پیش‌فرض تازه وارد آن معاینه شود. تغییر تنظیمات، معاینهٔ باز یا سوابق قبلی را تغییر نمی‌دهد.

۴. مشخصات و تاریخ معاینه را وارد کنید. تاریخ اولیه، تاریخ محلی همان روز ویندوز است. نمونهٔ ورودی معتبر: 1405/08/10 یا 2026-11-01؛ ارقام فارسی نیز پذیرفته می‌شوند. زمان واقعی هر مانور جدا ثبت می‌شود. باز کردن پروندهٔ قدیمی تاریخش را به امروز تغییر نمی‌دهد.

۵. یک یا چند مانور با «شروع تست» / «تست بعدی» انجام دهید. توقف دستی، مانور را ناقص نگه می‌دارد؛ بهترین مقادیر از مانورهای کامل با سیگنال کافی انتخاب می‌شوند. تعداد مانورها را کارشناس تعیین می‌کند، با سقف محافظتی ۱۰۰ مانور در پرونده. «حالت آزمایشی» صریح و دارای برچسب ساختگی است؛ قطع USB باعث شروع خودکار آن نمی‌شود.

۶. در صورت نیاز، تفسیر کارشناس را وارد کنید. VEXT اختیاری است؛ مقدار دستی فقط همراه نام کارشناس، منبع و تیک بازبینی پذیرفته می‌شود. خالی ماندن، در JSON برابر null است. مقدار دستی به‌عنوان خروجی تأییدشدهٔ دستگاه معرفی نمی‌شود.

۷. «پایان و گزارش» معاینه را نهایی و ذخیره می‌کند؛ پس از آن مشخصات و مانورها ثابت‌اند. با «ذخیره JPG + JSON» یک پوشهٔ یکتا با دقیقاً دو فایل بسازید. تصویر و داده از یک snapshot هستند. پوشهٔ خروجی قبلی بازنویسی نمی‌شود؛ برای نسخهٔ دومِ همان گزارش مقصد دیگری انتخاب کنید. برای مراجع یا معاینهٔ تازه «مراجع جدید» را بزنید.

تنظیمات: %APPDATA%\SpiroLab\settings.xml؛ سوابق: %APPDATA%\SpiroLab\exams. برای انتقال، از پوشهٔ دادهٔ خود پشتیبان بگیرید. برنامهٔ معمولی Administrator لازم ندارد؛ نصب درایور جداگانه به دسترسی مدیر سیستم نیاز دارد.

«وضعیت دستگاه» تشخیص ویندوز، درایور، بازشدن رابط، پاسخ کنترل، فرمان شروع، بسته‌ها و نمونه‌های decoded را جدا گزارش می‌کند. یافتن USB یا پاسخ فرمان به‌تنهایی تأیید اندازه‌گیری نیست. خروجی وضعیت شامل نام یا کد ملی بیمار نیست.
